# Native Remotion pixel oracle

This 64 x 64 transparent diagnostic is not an artistic delivery. Half-alpha red
tracks parent Sequence local frames, green tracks a nested Sequence, and blue
tracks root frames. White patches prove imported and public/staticFile images.
A green typography patch proves local IBM Plex Mono metrics; red means fallback.
A delayed cyan patch proves asynchronous React state, lazy loading and native
delayRender readiness. Hard boundaries are deliberate, independently checked.
No remote assets, reference song or character artwork is used.

The separate media mode uses a synthetic 60-frame, 30fps, 64 x 32 silent WebM.
Six black/white columns encode the source frame number; the bottom color band
changes every 20 frames. Two stacked videos independently exercise nested
Sequence + trim + 2x rate and an eight-frame trimmed native loop. Tests request
frames out of order, including a fresh page starting after the first loop ended.
No fades or interpolation may obscure the frame-number oracle. The encoder
helper only creates test input; final output still uses Rocut SceneExporter.
