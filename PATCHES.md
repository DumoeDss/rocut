# Patch log

Every local modification to a file inherited from upstream OpenCut Classic
(`cf5e79e919144200294fb9fed22a222592a0aeea`) is recorded here. The pinned upstream commit must stay
identifiable as the baseline, so a reader can reconstruct exactly what this fork changed and why.

> **This table must be appended to by every task that modifies an upstream file — as the change is
> made, not retroactively.** A modified upstream file with no row here is a defect. New files added
> by this fork are not patches and are not listed; see `UPSTREAM.md` for the added-file inventory.

Verify the set of modified files against the pin with:

```
git diff --name-only cf5e79e919144200294fb9fed22a222592a0aeea -- apps rust script
```

Columns:

- **id** — stable patch identifier (`P-nnn`), referenced from code comments where useful.
- **upstream path** — repo-relative path of the inherited file.
- **change** — what was actually altered.
- **rationale** — why, including the Slice spec clause that forces it. A patch with no forcing
  clause is scope creep.
- **verification** — how the patch was confirmed not to change behaviour (or what behaviour change
  was accepted).
