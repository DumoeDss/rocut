## Implementation notes

### Strict browser row classification

- `decodeStoredProject` treats presence of the current envelope property as authoritative. An invalid current envelope, record/summary ID mismatch, or unknown non-legacy row returns undecodable; it never falls back to legacy reinterpretation.
- Legacy projects are recognized only by a legacy metadata record, scenes array, or numeric project version.
- `decodeStoredAttachment` validates the complete current envelope, including revision, project ID, key identity, and body key. Current-envelope failure cannot fall back to raw legacy metadata.
- `decodeStoredLibraryRecord` requires the current envelope and exact encoded outer identity. Only the explicit raw `user-sounds` row remains a recognized legacy library representation.
- Browser list/load methods translate every present undecodable row into a payload-free, mechanism-neutral `ProjectStoreError({ code: "corrupt", operation, scope })`; absence continues to return an empty list or `null` as appropriate.

### Duplicate cleanup ordering

- Creation attempts settle as a group.
- Every fulfilled save contributes its ID to the cleanup set, including a save that succeeds after a sibling has already rejected.
- The first creation error is reported only after all fulfilled duplicates have been removed with awaited `Promise.allSettled` cleanup.

### Mid-flight read cancellation

- `readyForRead` rechecks the signal after store readiness, including the readiness-error path so an intervening abort wins.
- `readAfterDispatch` starts the I/O, exposes a conformance-only post-dispatch pause, awaits the I/O, then rechecks the signal before publication. If both I/O and cancellation occur, the typed cancellation wins.
- The wrapper covers project list/load, attachment list/load metadata and OPFS bodies, library list/load including the legacy read, and storage inspection.
- The attachment probe pauses on its second dispatch so the active abort occurs after the OPFS body read has been issued, not merely after metadata lookup.
