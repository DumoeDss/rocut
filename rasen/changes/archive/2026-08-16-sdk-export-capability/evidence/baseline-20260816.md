## LEAD addendum (2026-08-16, after Group B) — the isolated-process timeout family is environmental

The baseline run above (47.18s, 6 fail) happened on a fast machine state. Later
full-suite runs on the same tree — and, decisively, on the UNCHANGED
`rocut-wt-eco` worktree at the same base commit — show the
"…runs in an isolated … process" wrappers taking 6–16s against bun's 5s
default test timeout (e.g. `session-lifecycle.test.ts` standalone: 7.07s in
this worktree, 6.42s in eco — both >5s, both red for the same reason; loaded
full runs: 329–343s wall vs 47s baseline, 21–15 fails, every extra failure a
~5.0–16s timeout-signature member of that wrapper family). Machine-state
dependent, tree-independent. The no-regression gate therefore compares the
DETERMINISTIC failure set (the 6 above) and treats wrapper-timeout failures as
environmental, with this eco cross-proof as the record. CI (fast runners, bun
1.2.18) is the authority for that family.
